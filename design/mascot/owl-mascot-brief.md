# Маскот ПланТакт — шаблон и точки опоры

Файл `owl-mascot-template.svg` — текущий совёнок с уже разбитыми слоями. Перерисовывай своего
персонажа, **сохраняя структуру групп, их `id` и точки опоры** — тогда он встанет на место без
переделки кода.

## Общие правила
- Формат: **SVG**, единый `viewBox` (можно оставить `0 0 200 210`). Мастер можно рисовать крупнее (напр. 512×512) — отмасштабируем.
- Фон прозрачный. Только **плоские заливки**, без градиентов, теней, обводок-эффектов и растра.
- Каждая подвижная часть — отдельная `<g id="…">`. Статичные части можно объединять.
- Отображается ~170–180 px. Для растрового запаса (если понадобится): 180 / 360 / 540 px (1×/2×/3×), прозрачный фон.

## Слои и анимация

| id (группа) | Что это | Анимация | Точка опоры (`data-pivot`) |
|---|---|---|---|
| `owl` | вся сова целиком | pop-in (пружинка при появлении) + покачивание вверх-вниз | `100 190` (низ по центру — «прыжок от пола») |
| `glow` | сияние-фон | пульсация масштаба/прозрачности | `100 110` (центр) |
| `wingLeft` | левое крыло | махание вращением, ~ +6°…−26° | `46 96` (плечо) |
| `wingRight` | правое крыло | махание, зеркально ~ −6°…+26° | `154 96` (плечо) |
| `lidL` / `lidR` | веки | моргание — сжатие по вертикали (scaleY 0→1) | центр глаза: `76 92` / `124 92` |
| `pupilL` / `pupilR` | зрачки | лёгкий взгляд по сторонам (сдвиг по X) | центр зрачка: `76 94` / `124 94` |
| `body`, `belly` | тело и живот | — | — |
| `earTufts` | ушки-кисточки | — | — |
| `eyeWhiteL/R`, `glintL/R` | белки глаз и блики | — | — |
| `cheeks` | щёчки | — | — |
| `beak` | клюв | — | — |
| `feet` | лапки | — | — |

## Палитра (текущая, можно менять — сообщи новые значения)
- Тело: `#58cc02` · тень тела и крылья: `#46a302` · живот: `#d7ffb8`
- Клюв и лапки: `#ff9600` · зрачки: `#3a3a3a` · щёки: `#ff8fa3` · сияние: `#eaffd6`

## Состояния
Персонаж один, отличается только реплика и цвет конфетти (конфетти рисует код):
- создана задача, создано мероприятие, задача выполнена.
- По желанию можно дать **вторую, «праздничную» позу** (лапки вверх / салют) для «задача выполнена».

## Если хочешь более богатую анимацию (как у Дуолинго)
Вместо послойного SVG можно сделать **Lottie** (After Effects → плагин Bodymovin → JSON):
30–60 fps, длительность ~2–3.4 с, зацикленная спокойная часть + «выброс» с эмоцией, фон прозрачный.
Тогда пришли `.json` — подключим через `lottie-react`.
